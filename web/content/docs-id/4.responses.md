# Responses

`POST /v1/responses` menerima permintaan dalam format Responses dan menjawab dalam format yang sama. Klien dan SDK yang dibuat untuk format tersebut langsung berfungsi setelah Anda mengganti base URL-nya menjadi `https://gateway.example.com/v1`.

## Stateless

Gateway tidak menyimpan apa pun di antara permintaan. Kirim seluruh percakapan di `input` setiap kali. Anda dapat mengirim kembali item output sebelumnya (pesan, reasoning, function call) sebagai item input, tanpa perubahan. Jika permintaan tidak menyertakan `store`, gateway menganggap nilainya `false`.

Fitur berikut memerlukan state yang tersimpan, jadi gateway menolaknya dengan `400 invalid_request`: `store: true`, `previous_response_id`, `conversation`, `background: true`, dan prompt tersimpan (`prompt`).

## Permintaan

::code-tabs
```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "instructions": "You are a concise assistant.",
    "input": "Say hello in one sentence.",
    "max_output_tokens": 256
  }'
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const response = await client.responses.create({
  model: "my-model",
  input: "Say hello in one sentence.",
});

console.log(response.output_text);
```
::

Responsnya adalah objek `response` dengan `status: "completed"` (atau `"incomplete"` dengan `incomplete_details.reason`), item `output`-nya, dan `usage`.

Percakapan dengan giliran sebelumnya:

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": [
      { "role": "user", "content": "My name is Ada." },
      { "role": "assistant", "content": "Nice to meet you, Ada." },
      { "role": "user", "content": "What is my name?" }
    ]
  }'
```

## Streaming

Atur `"stream": true` untuk menerima server-sent events bernama dengan urutan berikut. Pertama `response.created` dan `response.in_progress`. Lalu event item output (`response.output_item.added`, `response.output_text.delta`, `response.function_call_arguments.delta`, ...). Terakhir `response.completed` atau `response.incomplete` dengan respons lengkap dan penggunaan tokennya.

::code-tabs
```bash
curl -N https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": "Say hello in one sentence.",
    "stream": true
  }'
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const stream = await client.responses.create({
  model: "my-model",
  input: "Say hello in one sentence.",
  stream: true,
});

for await (const event of stream) {
  if (event.type === "response.output_text.delta") {
    process.stdout.write(event.delta);
  }
}
```
::

Jika permintaan gagal setelah stream dimulai, event terakhir adalah `event: error` dengan `{ "type": "error", "code": "...", "message": "..." }`, dan `response.completed` tidak menyusul.

## Parameter lain

- **Reasoning:** `reasoning.effort` (`none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`). Reasoning kembali sebagai item output `reasoning`. Kirim kembali item tersebut tanpa perubahan di giliran berikutnya.
- **Output terstruktur:** `text.format` dengan `{ "type": "json_schema", "name": "...", "schema": { ... } }` atau `{ "type": "json_object" }`.
- **Sampling:** `temperature`, `top_p`, `max_output_tokens`.
- **Gambar dan tool:** lihat [Mengirim gambar](/id/docs/images) dan [Menggunakan tool](/id/docs/tools).

## Ditolak

Selain fitur stateful di atas, hal berikut mendapat `400 invalid_request`:

- Tool selain `function`, seperti pencarian web, pencarian file, code interpreter, atau MCP.
- Item input selain pesan, reasoning, function call, dan output function call.
- Content part selain teks dan gambar, seperti `input_file` atau `input_audio`.
- Gambar yang diberikan melalui `file_id`. Kirim `image_url` sebagai gantinya.
