# Responses

`POST /v1/responses` menerima _request_ dalam format Responses dan membalas dalam format yang sama. _Client_ dan SDK untuk format ini langsung bisa dipakai setelah Anda mengganti _base URL_-nya menjadi `https://gateway.example.com/v1`.

## Stateless

_Gateway_ tidak menyimpan apa pun di antara _request_. Kirim seluruh percakapan di `input` setiap kali. Anda bisa mengirim balik _output item_ sebelumnya (_message_, _reasoning_, _function call_) sebagai _input item_, tanpa diubah. Jika _request_ tidak menyertakan `store`, _gateway_ menganggap nilainya `false`.

Fitur berikut butuh _state_ tersimpan, jadi _gateway_ menolaknya dengan `400 invalid_request`: `store: true`, `previous_response_id`, `conversation`, `background: true`, dan _stored prompt_ (`prompt`).

## Request

::code-tabs
```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "instructions": "You are a concise assistant.",
    "input": "Say hello in one sentence.",
    "max_output_tokens": 256
  }'
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const response = await client.responses.create({
  model: "my-model",
  input: "Say hello in one sentence.",
});

console.log(response.output_text);
```
::

_Response_-nya berupa objek `response` dengan `status: "completed"` (atau `"incomplete"` beserta `incomplete_details.reason`), _item_ `output`, dan `usage`.

Contoh percakapan dengan _turn_ sebelumnya:

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": [
      { "role": "user", "content": "My name is Ada." },
      { "role": "assistant", "content": "Nice to meet you, Ada." },
      { "role": "user", "content": "What is my name?" }
    ]
  }'
```

## Streaming

Tambahkan `"stream": true` untuk menerima _server-sent events_ bernama, dengan urutan berikut:

1. `response.created` dan `response.in_progress`.
2. _Event_ _output item_ (`response.output_item.added`, `response.output_text.delta`, `response.function_call_arguments.delta`, ...).
3. `response.completed` atau `response.incomplete`, berisi _response_ lengkap beserta pemakaian tokennya.

::code-tabs
```bash
curl -N https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": "Say hello in one sentence.",
    "stream": true
  }'
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const stream = await client.responses.create({
  model: "my-model",
  input: "Say hello in one sentence.",
  stream: true,
});

for await (const event of stream) {
  if (event.type === "response.output_text.delta") {
    process.stdout.write(event.delta);
  }
}
```
::

Jika _request_ gagal setelah _stream_ berjalan, _event_ terakhir adalah `event: error` yang berisi `{ "type": "error", "code": "...", "message": "..." }`, dan tidak ada `response.completed` sesudahnya.

## Parameter lain

- **_Reasoning_:** `reasoning.effort` (`none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`). _Reasoning_ dikirim sebagai _output item_ `reasoning`. Kirim balik _item_ tersebut tanpa diubah di _turn_ berikutnya.
- **_Structured output_:** `text.format` dengan `{ "type": "json_schema", "name": "...", "schema": { ... } }` atau `{ "type": "json_object" }`.
- **_Sampling_:** `temperature`, `top_p`, `max_output_tokens`.
- **Gambar dan _tool_:** lihat [Gambar](/id/docs/images) dan [Tool](/id/docs/tools).

## Tidak didukung

Selain fitur _stateful_ di atas, _gateway_ juga menolak hal-hal berikut dengan `400 invalid_request`:

- _Tool_ selain `function`, misalnya _web search_, _file search_, _code interpreter_, atau MCP.
- _Input item_ selain _message_, _reasoning_, _function call_, dan _function call output_.
- _Content part_ selain teks dan gambar, misalnya `input_file` atau `input_audio`.
- Gambar lewat `file_id`. Kirim `image_url`.
