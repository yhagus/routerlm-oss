# Mengirim gambar

Setiap endpoint menerima gambar di pesan pengguna, baik melalui URL maupun secara inline sebagai data base64. Model memerlukan kapabilitas `vision` (lihat [Models](/id/docs/models)). Jika Model tidak memilikinya, permintaan mendapat `400 no_capable_route`.

Gambar inline dihitung dalam batas body permintaan 20 MB. Gateway tidak pernah menyimpan gambar tersebut.

Setiap contoh di bawah mengirim satu gambar melalui URL dan satu gambar secara inline. Ganti `https://example.com/photo.png` dengan URL gambar Anda. Ganti PNG inline 1×1 dengan data base64 dan media type gambar Anda.

## Chat Completions

Gunakan content part `image_url`. Nilai `url`-nya adalah URL web atau URL `data:`.

```bash
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      {
        "role": "user",
        "content": [
          { "type": "text", "text": "What is in this image?" },
          { "type": "image_url", "image_url": { "url": "https://example.com/photo.png" } },
          { "type": "image_url", "image_url": { "url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg==" } }
        ]
      }
    ]
  }'
```

## Messages

Gunakan content block `image` dengan sumber `url` atau `base64`.

```bash
curl https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "messages": [
      {
        "role": "user",
        "content": [
          { "type": "text", "text": "What is in this image?" },
          { "type": "image", "source": { "type": "url", "url": "https://example.com/photo.png" } },
          {
            "type": "image",
            "source": {
              "type": "base64",
              "media_type": "image/png",
              "data": "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="
            }
          }
        ]
      }
    ]
  }'
```

## Responses

Gunakan content part `input_image`. Nilai `image_url`-nya adalah URL web atau URL `data:`. Gateway tidak menyimpan file, jadi gateway menolak gambar melalui `file_id`.

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": [
      {
        "role": "user",
        "content": [
          { "type": "input_text", "text": "What is in this image?" },
          { "type": "input_image", "image_url": "https://example.com/photo.png" },
          { "type": "input_image", "image_url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg==" }
        ]
      }
    ]
  }'
```
