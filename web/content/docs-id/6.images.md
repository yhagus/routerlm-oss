# Gambar

Semua _endpoint_ menerima gambar di _user message_, lewat URL atau _inline_ sebagai data base64. Model harus punya _capability_ `vision` (lihat [Daftar Model](/id/docs/models)). Jika tidak, _request_ ditolak dengan `400 no_capable_route`.

Gambar _inline_ ikut dihitung dalam batas _request body_ 20 MB. _Gateway_ tidak pernah menyimpan gambar tersebut.

Setiap contoh di bawah mengirim satu gambar lewat URL dan satu gambar _inline_. Ganti `https://example.com/photo.png` dengan URL gambar Anda. Ganti PNG _inline_ 1×1 dengan data base64 dan _media type_ gambar Anda.

## Chat Completions

Pakai _content part_ `image_url`. Isi `url`-nya berupa URL web atau URL `data:`.

```bash
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      {
        "role": "user",
        "content": [
          { "type": "text", "text": "What is in this image?" },
          { "type": "image_url", "image_url": { "url": "https://example.com/photo.png" } },
          { "type": "image_url", "image_url": { "url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg==" } }
        ]
      }
    ]
  }'
```

## Messages

Pakai _content block_ `image` dengan _source_ `url` atau `base64`.

```bash
curl https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "messages": [
      {
        "role": "user",
        "content": [
          { "type": "text", "text": "What is in this image?" },
          { "type": "image", "source": { "type": "url", "url": "https://example.com/photo.png" } },
          {
            "type": "image",
            "source": {
              "type": "base64",
              "media_type": "image/png",
              "data": "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="
            }
          }
        ]
      }
    ]
  }'
```

## Responses

Pakai _content part_ `input_image`. Isi `image_url`-nya berupa URL web atau URL `data:`. _Gateway_ tidak menyimpan _file_, jadi gambar lewat `file_id` ditolak.

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": [
      {
        "role": "user",
        "content": [
          { "type": "input_text", "text": "What is in this image?" },
          { "type": "input_image", "image_url": "https://example.com/photo.png" },
          { "type": "input_image", "image_url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg==" }
        ]
      }
    ]
  }'
```
