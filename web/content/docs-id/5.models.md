# Daftar Model

`GET /v1/models` menampilkan Model yang boleh dipakai API Key Anda, urut berdasarkan nama. Pakai `id` dari daftar ini sebagai nilai `model` di _request_ inferensi.

::code-tabs
```bash
curl https://gateway.example.com/v1/models \
  -H "Authorization: Bearer $ROUTERLM_API_KEY"
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

for await (const model of client.models.list()) {
  console.log(model.id);
}
```
::

Bentuk _response_-nya sama dengan daftar model yang dikenali _client_ Chat Completions, ditambah _field_ `kind` dan `capabilities` milik Model:

```json
{
  "object": "list",
  "data": [
    {
      "id": "my-model",
      "object": "model",
      "created": 1794700000,
      "owned_by": "routerlm",
      "kind": "chat",
      "capabilities": ["vision", "tools", "reasoning", "structured-output"]
    }
  ]
}
```

`kind` menunjukkan _endpoint_ mana yang melayani Model tersebut:

| Kind | Endpoint |
| --- | --- |
| `chat` | [Chat Completions](/id/docs/chat-completions), [Messages](/id/docs/messages), dan [Responses](/id/docs/responses) |
| `image` | [`POST /v1/images/generations` dan `POST /v1/images/edits`](/id/docs/media#membuat-gambar) |
| `speech` | [`POST /v1/audio/speech`](/id/docs/media#speech) |
| `transcription` | [`POST /v1/audio/transcriptions`](/id/docs/media#transkripsi) |
| `video` | [`POST /v1/videos`](/id/docs/media#video) |

Model yang dikirim ke _endpoint_ untuk Kind lain ditolak dengan `400 invalid_request`.

`capabilities` menunjukkan fitur apa saja yang boleh dipakai _request_ ke Model tersebut:

| Capability | Request yang membutuhkannya |
| --- | --- |
| `vision` | [Input gambar](/id/docs/images) |
| `tools` | [Function tool](/id/docs/tools) |
| `reasoning` | Pengaturan _reasoning effort_ atau _thinking_ |
| `structured-output` | _Response format_ dengan JSON schema |
| `text-to-video` | [Video](/id/docs/media#video) dari _prompt_ saja |
| `first-frame` | Video yang dimulai dari gambar tertentu |
| `last-frame` | Video yang diakhiri dengan gambar tertentu |
| `reference-images` | Video yang dipandu gambar referensi |

_Request_ yang membutuhkan _capability_ yang tidak dimiliki Model ditolak dengan `400 no_capable_route`.
