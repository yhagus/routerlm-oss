# Models

`GET /v1/models` menampilkan daftar Model yang boleh dipakai oleh API Key Anda, diurutkan berdasarkan nama. Gunakan `id` dari daftar ini sebagai `model` pada permintaan inferensi.

::code-tabs
```bash
curl https://gateway.example.com/v1/models \
  -H "Authorization: Bearer $ROUTERLM_API_KEY"
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

for await (const model of client.models.list()) {
  console.log(model.id);
}
```
::

Responsnya memiliki bentuk daftar model yang diharapkan oleh klien Chat Completions, ditambah `capabilities` milik Model:

```json
{
  "object": "list",
  "data": [
    {
      "id": "my-model",
      "object": "model",
      "created": 1794700000,
      "owned_by": "routerlm",
      "capabilities": ["vision", "tools", "reasoning", "structured-output"]
    }
  ]
}
```

`capabilities` menyatakan apa yang boleh dipakai oleh permintaan ke Model tersebut:

| Kapabilitas | Permintaan yang memerlukannya |
| --- | --- |
| `vision` | [Input gambar](/id/docs/images) |
| `tools` | [Function tool](/id/docs/tools) |
| `reasoning` | Pengaturan reasoning effort atau thinking |
| `structured-output` | Format respons dengan JSON schema |

Permintaan yang memerlukan kapabilitas yang tidak dimiliki Model mendapat `400 no_capable_route`.
