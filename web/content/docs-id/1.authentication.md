# Autentikasi

Setiap permintaan memerlukan API Key. Minta API Key kepada operator gateway. Dashboard hanya menampilkan API Key baru satu kali, jadi simpan di tempat yang aman. API Key dapat dibatasi untuk beberapa Model saja, dan API Key dapat kedaluwarsa.

Kirim key di salah satu dari dua header. Keduanya berfungsi di setiap endpoint.

## Bearer token

Header `Authorization`, yang dikirim oleh SDK `openai`:

```bash
curl https://gateway.example.com/v1/models \
  -H "Authorization: Bearer $ROUTERLM_API_KEY"
```

## `x-api-key`

Header yang dikirim oleh SDK `@anthropic-ai/sdk`:

```bash
curl https://gateway.example.com/v1/models \
  -H "x-api-key: $ROUTERLM_API_KEY"
```

Jika permintaan memiliki kedua header, gateway memakai `Authorization`.

## Jika key ditolak

Key yang tidak ada, salah, dicabut, atau kedaluwarsa mendapat `401 invalid_api_key`. Key yang tidak boleh memakai Model yang diminta mendapat `403 model_not_allowed`. Lihat [Error](/id/docs/errors).
