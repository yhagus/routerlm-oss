# Autentikasi

Setiap _request_ wajib menyertakan API Key. Minta API Key kepada operator _gateway_. _Dashboard_ hanya menampilkan API Key baru satu kali. Simpan API Key tersebut di tempat yang aman. API Key bisa dibatasi hanya untuk Model tertentu, dan bisa kedaluwarsa.

Kirim API Key lewat salah satu dari dua _header_ berikut. Keduanya berlaku di semua _endpoint_.

## Bearer token

_Header_ `Authorization`, yang dikirim oleh SDK `openai`:

```bash
curl https://gateway.example.com/v1/models \
  -H "Authorization: Bearer $ROUTERLM_API_KEY"
```

## `x-api-key`

_Header_ yang dikirim oleh SDK `@anthropic-ai/sdk`:

```bash
curl https://gateway.example.com/v1/models \
  -H "x-api-key: $ROUTERLM_API_KEY"
```

Jika _request_ membawa kedua _header_, _gateway_ memakai `Authorization`.

## Jika API Key ditolak

_Request_ tanpa API Key, atau dengan API Key yang salah, dicabut, atau kedaluwarsa, ditolak dengan `401 invalid_api_key`. _Request_ dengan API Key yang tidak diizinkan memakai Model yang diminta ditolak dengan `403 model_not_allowed`. Lihat [Error](/id/docs/errors).
