# Messages

`POST /v1/messages` menerima _request_ dalam format Messages dan membalas dalam format yang sama. _Client_ dan SDK untuk format ini langsung bisa dipakai setelah Anda mengganti _base URL_-nya menjadi `https://gateway.example.com`. Sesuai format Messages, setiap _request_ wajib berisi `max_tokens`.

## Request

::code-tabs
```bash
curl https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "system": "You are a concise assistant.",
    "messages": [{ "role": "user", "content": "Say hello in one sentence." }]
  }'
```
```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://gateway.example.com",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const message = await client.messages.create({
  model: "my-model",
  max_tokens: 256,
  messages: [{ role: "user", content: "Say hello in one sentence." }],
});

console.log(message.content);
```
::

_Response_-nya berupa objek `message`. _Field_ `model` berisi nama Model yang Anda kirim. _Field_ `usage` berisi `input_tokens`, `output_tokens`, `cache_read_input_tokens`, dan `cache_creation_input_tokens`.

## Streaming

Tambahkan `"stream": true` untuk menerima _server-sent events_ bernama, dengan urutan berikut:

1. `message_start`.
2. `content_block_start`, `content_block_delta`, dan `content_block_stop` untuk setiap blok.
3. `message_delta`, berisi _stop reason_ dan pemakaian token.
4. `message_stop`.

::code-tabs
```bash
curl -N https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "messages": [{ "role": "user", "content": "Say hello in one sentence." }],
    "stream": true
  }'
```
```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://gateway.example.com",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const stream = client.messages
  .stream({
    model: "my-model",
    max_tokens: 256,
    messages: [{ role: "user", content: "Say hello in one sentence." }],
  })
  .on("text", (text) => process.stdout.write(text));

const message = await stream.finalMessage();
console.log(message.usage);
```
::

Jika _request_ gagal setelah _stream_ berjalan, _event_ terakhir adalah `event: error` yang berisi _error body_ (lihat [Error](/id/docs/errors)), dan tidak ada `message_stop` sesudahnya.

## Parameter lain

- **_Reasoning_:** `thinking` (`enabled` dengan `budget_tokens`, `adaptive`, atau `disabled`) dan `output_config.effort`. Blok _thinking_ dikirim bersama `signature`-nya. Kirim balik blok tersebut tanpa diubah di _turn_ berikutnya.
- **_Structured output_:** `output_config.format` dengan `{ "type": "json_schema", "schema": { ... } }`.
- **_Prompt caching_:** _gateway_ menerapkan `cache_control` pada blok _system_, _text_, _image_, _tool_, dan _tool result_, juga di level teratas.
- **_Sampling_:** `temperature`, `top_p`, `stop_sequences`.
- **Gambar dan _tool_:** lihat [Gambar](/id/docs/images) dan [Tool](/id/docs/tools).

## Tidak didukung

_Gateway_ menolak hal-hal berikut dengan `400 invalid_request`:

- _Server tool_, yaitu semua jenis _tool_ selain _custom tool_.
- _Content block_ selain _text_, _image_, _tool use_, _tool result_, dan _thinking_, misalnya `document` dan `search_result`.
- Sumber gambar selain `base64` dan `url`, misalnya `file`.
- `role: "system"` di dalam `messages`. Pakai _field_ `system`.
- `mcp_servers`.
