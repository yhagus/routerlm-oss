# Messages

`POST /v1/messages` menerima permintaan dalam format Messages dan menjawab dalam format yang sama. Klien dan SDK yang dibuat untuk format tersebut langsung berfungsi setelah Anda mengganti base URL-nya menjadi `https://gateway.example.com`. Sesuai format Messages, setiap permintaan wajib mengatur `max_tokens`.

## Permintaan

::code-tabs
```bash
curl https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "system": "You are a concise assistant.",
    "messages": [{ "role": "user", "content": "Say hello in one sentence." }]
  }'
```
```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://gateway.example.com",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const message = await client.messages.create({
  model: "my-model",
  max_tokens: 256,
  messages: [{ role: "user", content: "Say hello in one sentence." }],
});

console.log(message.content);
```
::

Responsnya adalah objek `message`. Nilai `model` di dalamnya adalah nama Model yang Anda kirim. `usage` melaporkan `input_tokens`, `output_tokens`, `cache_read_input_tokens`, dan `cache_creation_input_tokens`.

## Streaming

Atur `"stream": true` untuk menerima server-sent events bernama dengan urutan berikut. Pertama `message_start`. Lalu `content_block_start`, `content_block_delta`, dan `content_block_stop` untuk setiap blok. Lalu `message_delta` dengan alasan berhenti dan penggunaan token. Terakhir `message_stop`.

::code-tabs
```bash
curl -N https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "messages": [{ "role": "user", "content": "Say hello in one sentence." }],
    "stream": true
  }'
```
```ts
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: "https://gateway.example.com",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const stream = client.messages
  .stream({
    model: "my-model",
    max_tokens: 256,
    messages: [{ role: "user", content: "Say hello in one sentence." }],
  })
  .on("text", (text) => process.stdout.write(text));

const message = await stream.finalMessage();
console.log(message.usage);
```
::

Jika permintaan gagal setelah stream dimulai, event terakhir adalah `event: error` dengan error envelope (lihat [Error](/id/docs/errors)), dan `message_stop` tidak menyusul.

## Parameter lain

- **Reasoning:** `thinking` (`enabled` dengan `budget_tokens`, `adaptive`, atau `disabled`) dan `output_config.effort`. Blok thinking kembali bersama `signature`-nya. Kirim kembali blok tersebut tanpa perubahan di giliran berikutnya.
- **Output terstruktur:** `output_config.format` dengan `{ "type": "json_schema", "schema": { ... } }`.
- **Prompt caching:** gateway menerapkan `cache_control` pada blok system, teks, gambar, tool, dan hasil tool, serta di tingkat atas.
- **Sampling:** `temperature`, `top_p`, `stop_sequences`.
- **Gambar dan tool:** lihat [Mengirim gambar](/id/docs/images) dan [Menggunakan tool](/id/docs/tools).

## Ditolak

Hal berikut mendapat `400 invalid_request`:

- Server tool: semua jenis tool selain custom tool.
- Content block selain teks, gambar, tool use, tool result, dan thinking, seperti `document` dan `search_result`.
- Sumber gambar selain `base64` dan `url`, seperti `file`.
- `role: "system"` di dalam `messages`. Gunakan `system` sebagai gantinya.
- `mcp_servers`.
