# Tool

Semua _endpoint_ mendukung _function tool_. Alurnya ada tiga langkah:

1. Anda mendeklarasikan _function_ beserta JSON schema untuk argumennya.
2. Model bisa membalas dengan _tool call_ ke _function_ tersebut.
3. Anda menjalankan _function_ itu, lalu mengirim hasilnya di _request_ berikutnya.

Model harus punya _capability_ `tools` (lihat [Daftar Model](/id/docs/models)).

_Gateway_ hanya mendukung _function tool_. _Hosted tool_, seperti _web search_, _file search_, atau _code execution_, ditolak dengan `400 invalid_request`.

_Gateway_ bersifat _stateless_. Karena itu, _request_ yang membawa hasil _tool_ juga harus membawa percakapan sebelumnya, termasuk _tool call_ dari Model. Jangan ubah id _tool call_ yang Anda terima.

## Chat Completions

Deklarasikan _tool_ di `tools`. _Tool call_ ada di `message.tool_calls` dengan `finish_reason: "tool_calls"`. Kirim hasilnya sebagai _message_ `tool` dengan `tool_call_id` dari _tool call_ tersebut:

```bash
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      { "role": "user", "content": "What is the weather in Paris?" },
      {
        "role": "assistant",
        "content": null,
        "tool_calls": [
          {
            "id": "call_123",
            "type": "function",
            "function": { "name": "get_weather", "arguments": "{\"city\":\"Paris\"}" }
          }
        ]
      },
      { "role": "tool", "tool_call_id": "call_123", "content": "18°C, cloudy" }
    ],
    "tools": [
      {
        "type": "function",
        "function": {
          "name": "get_weather",
          "description": "Current weather for a city",
          "parameters": {
            "type": "object",
            "properties": { "city": { "type": "string" } },
            "required": ["city"]
          }
        }
      }
    ],
    "tool_choice": "auto"
  }'
```

`tool_choice` menerima `auto`, `none`, `required`, atau `{ "type": "function", "function": { "name": "get_weather" } }`. `parallel_tool_calls: false` meminta Model membuat paling banyak satu _tool call_ per _turn_.

## Messages

Deklarasikan _tool_ dengan `input_schema`. _Tool call_ dikirim sebagai blok `tool_use` dengan `stop_reason: "tool_use"`. Kirim hasilnya sebagai blok `tool_result` di _user message_ berikutnya:

```bash
curl https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "messages": [
      { "role": "user", "content": "What is the weather in Paris?" },
      {
        "role": "assistant",
        "content": [
          { "type": "tool_use", "id": "toolu_123", "name": "get_weather", "input": { "city": "Paris" } }
        ]
      },
      {
        "role": "user",
        "content": [{ "type": "tool_result", "tool_use_id": "toolu_123", "content": "18°C, cloudy" }]
      }
    ],
    "tools": [
      {
        "name": "get_weather",
        "description": "Current weather for a city",
        "input_schema": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    ]
  }'
```

## Responses

Deklarasikan _tool_ dengan `"type": "function"`. _Tool call_ dikirim sebagai _output item_ `function_call` dengan `call_id`. Kirim balik _tool call_ tersebut sebagai _input_, lalu tambahkan _item_ `function_call_output` dengan `call_id` yang sama:

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": [
      { "role": "user", "content": "What is the weather in Paris?" },
      {
        "type": "function_call",
        "call_id": "call_123",
        "name": "get_weather",
        "arguments": "{\"city\":\"Paris\"}"
      },
      { "type": "function_call_output", "call_id": "call_123", "output": "18°C, cloudy" }
    ],
    "tools": [
      {
        "type": "function",
        "name": "get_weather",
        "description": "Current weather for a city",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    ]
  }'
```

## Streaming tool call

Dengan `"stream": true`, argumen _tool call_ datang dalam beberapa potongan: `delta.tool_calls[].function.arguments` di Chat Completions, `input_json_delta` di Messages, dan `response.function_call_arguments.delta` di Responses. Gabungkan semua potongan dulu, baru _parse_ argumennya sebagai JSON.
