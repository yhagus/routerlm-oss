# Menggunakan tool

Setiap endpoint mendukung function tool. Alurnya terdiri dari tiga langkah:

1. Anda mendeklarasikan fungsi dengan JSON schema untuk argumennya.
2. Model dapat menjawab dengan panggilan ke fungsi tersebut.
3. Anda menjalankan fungsi dan mengirim hasilnya di permintaan berikutnya.

Model memerlukan kapabilitas `tools` (lihat [Models](/id/docs/models)).

Gateway hanya mendukung function tool. Gateway menolak hosted tool, seperti pencarian web, pencarian file, atau eksekusi kode, dengan `400 invalid_request`.

Gateway bersifat stateless. Karena itu, permintaan yang membawa hasil tool juga harus membawa percakapan sebelumnya, termasuk tool call dari Model. Pertahankan id tool call persis seperti yang Anda terima.

## Chat Completions

Deklarasikan tool di `tools`. Tool call kembali di `message.tool_calls` dengan `finish_reason: "tool_calls"`. Kirim hasilnya sebagai pesan `tool` dengan `tool_call_id` dari panggilan tersebut:

```bash
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      { "role": "user", "content": "What is the weather in Paris?" },
      {
        "role": "assistant",
        "content": null,
        "tool_calls": [
          {
            "id": "call_123",
            "type": "function",
            "function": { "name": "get_weather", "arguments": "{\"city\":\"Paris\"}" }
          }
        ]
      },
      { "role": "tool", "tool_call_id": "call_123", "content": "18°C, cloudy" }
    ],
    "tools": [
      {
        "type": "function",
        "function": {
          "name": "get_weather",
          "description": "Current weather for a city",
          "parameters": {
            "type": "object",
            "properties": { "city": { "type": "string" } },
            "required": ["city"]
          }
        }
      }
    ],
    "tool_choice": "auto"
  }'
```

`tool_choice` menerima `auto`, `none`, `required`, atau `{ "type": "function", "function": { "name": "get_weather" } }`. `parallel_tool_calls: false` meminta paling banyak satu panggilan per giliran.

## Messages

Deklarasikan tool dengan `input_schema`. Tool call kembali sebagai blok `tool_use` dengan `stop_reason: "tool_use"`. Kirim hasilnya sebagai blok `tool_result` di pesan pengguna berikutnya:

```bash
curl https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "messages": [
      { "role": "user", "content": "What is the weather in Paris?" },
      {
        "role": "assistant",
        "content": [
          { "type": "tool_use", "id": "toolu_123", "name": "get_weather", "input": { "city": "Paris" } }
        ]
      },
      {
        "role": "user",
        "content": [{ "type": "tool_result", "tool_use_id": "toolu_123", "content": "18°C, cloudy" }]
      }
    ],
    "tools": [
      {
        "name": "get_weather",
        "description": "Current weather for a city",
        "input_schema": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    ]
  }'
```

## Responses

Deklarasikan tool dengan `"type": "function"`. Tool call kembali sebagai item output `function_call` dengan `call_id`. Kirim kembali panggilan tersebut sebagai input, diikuti item `function_call_output` dengan `call_id` yang sama:

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": [
      { "role": "user", "content": "What is the weather in Paris?" },
      {
        "type": "function_call",
        "call_id": "call_123",
        "name": "get_weather",
        "arguments": "{\"city\":\"Paris\"}"
      },
      { "type": "function_call_output", "call_id": "call_123", "output": "18°C, cloudy" }
    ],
    "tools": [
      {
        "type": "function",
        "name": "get_weather",
        "description": "Current weather for a city",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    ]
  }'
```

## Streaming tool call

Dengan `"stream": true`, argumen tool call datang dalam beberapa potongan: `delta.tool_calls[].function.arguments` di Chat Completions, `input_json_delta` di Messages, dan `response.function_call_arguments.delta` di Responses. Gabungkan semua potongan sebelum mem-parse argumen sebagai JSON.
