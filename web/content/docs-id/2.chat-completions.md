# Chat Completions

`POST /v1/chat/completions` menerima _request_ dalam format Chat Completions dan membalas dalam format yang sama. _Client_ dan SDK untuk format ini langsung bisa dipakai setelah Anda mengganti _base URL_-nya menjadi `https://gateway.example.com/v1`.

## Request

::code-tabs
```bash
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      { "role": "system", "content": "You are a concise assistant." },
      { "role": "user", "content": "Say hello in one sentence." }
    ],
    "max_tokens": 256
  }'
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const completion = await client.chat.completions.create({
  model: "my-model",
  messages: [{ role: "user", content: "Say hello in one sentence." }],
});

console.log(completion.choices[0].message.content);
```
::

_Response_-nya berupa objek `chat.completion`. _Field_ `model` berisi nama Model yang Anda kirim. _Field_ `usage` berisi jumlah token yang terpakai, dan token _input_ dari _cache_ ada di `usage.prompt_tokens_details.cached_tokens`.

## Streaming

Tambahkan `"stream": true` untuk menerima _event_ `chat.completion.chunk` sebagai _server-sent events_. _Stream_ ditutup dengan `data: [DONE]`. Tambahkan juga `"stream_options": { "include_usage": true }` untuk menerima _chunk_ terakhir yang berisi pemakaian token.

::code-tabs
```bash
curl -N https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [{ "role": "user", "content": "Say hello in one sentence." }],
    "stream": true,
    "stream_options": { "include_usage": true }
  }'
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const stream = await client.chat.completions.create({
  model: "my-model",
  messages: [{ role: "user", content: "Say hello in one sentence." }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
```
::

Jika _request_ gagal setelah _stream_ berjalan, _event_ terakhir berisi _error body_ (lihat [Error](/id/docs/errors)), dan tidak ada `data: [DONE]` sesudahnya.

## Parameter lain

- **_Reasoning_:** `reasoning_effort` (`none`, `minimal`, `low`, `medium`, `high`, `xhigh`). Teks _reasoning_ ada di `reasoning_content`, baik di _message_ maupun di _delta_ _stream_.
- **_Structured output_:** `response_format` dengan `{ "type": "json_schema", "json_schema": { "name": "...", "schema": { ... } } }` atau `{ "type": "json_object" }`.
- **_Sampling_:** `temperature`, `top_p`, `stop`, `max_tokens` atau `max_completion_tokens`.
- **Gambar dan _tool_:** lihat [Gambar](/id/docs/images) dan [Tool](/id/docs/tools).

## Tidak didukung

_Gateway_ menolak hal-hal berikut dengan `400 invalid_request`:

- `n` selain 1.
- _Output_ audio (`audio`, `modalities`).
- `web_search_options`.
- _Field_ lama `functions` dan _role_ `function`. Pakai `tools` dan _role_ `tool`.
- _Tool_ selain `function`.
- _Content part_ selain teks dan gambar.
