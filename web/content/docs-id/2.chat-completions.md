# Chat Completions

`POST /v1/chat/completions` menerima permintaan dalam format Chat Completions dan menjawab dalam format yang sama. Klien dan SDK yang dibuat untuk format tersebut langsung berfungsi setelah Anda mengganti base URL-nya menjadi `https://gateway.example.com/v1`.

## Permintaan

::code-tabs
```bash
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      { "role": "system", "content": "You are a concise assistant." },
      { "role": "user", "content": "Say hello in one sentence." }
    ],
    "max_tokens": 256
  }'
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const completion = await client.chat.completions.create({
  model: "my-model",
  messages: [{ role: "user", content: "Say hello in one sentence." }],
});

console.log(completion.choices[0].message.content);
```
::

Responsnya adalah objek `chat.completion`. Nilai `model` di dalamnya adalah nama Model yang Anda kirim. `usage` melaporkan token yang terpakai. Input dari cache tercantum di `usage.prompt_tokens_details.cached_tokens`.

## Streaming

Atur `"stream": true` untuk menerima event `chat.completion.chunk` sebagai server-sent events. Stream diakhiri dengan `data: [DONE]`. Tambahkan `"stream_options": { "include_usage": true }` untuk menerima chunk terakhir yang berisi penggunaan token.

::code-tabs
```bash
curl -N https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [{ "role": "user", "content": "Say hello in one sentence." }],
    "stream": true,
    "stream_options": { "include_usage": true }
  }'
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const stream = await client.chat.completions.create({
  model: "my-model",
  messages: [{ role: "user", content: "Say hello in one sentence." }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
}
```
::

Jika permintaan gagal setelah stream dimulai, event terakhir adalah error envelope (lihat [Error](/id/docs/errors)), dan `data: [DONE]` tidak menyusul.

## Parameter lain

- **Reasoning:** `reasoning_effort` (`none`, `minimal`, `low`, `medium`, `high`, `xhigh`). Teks reasoning kembali di `reasoning_content` pada pesan dan pada delta stream.
- **Output terstruktur:** `response_format` dengan `{ "type": "json_schema", "json_schema": { "name": "...", "schema": { ... } } }` atau `{ "type": "json_object" }`.
- **Sampling:** `temperature`, `top_p`, `stop`, `max_tokens` atau `max_completion_tokens`.
- **Gambar dan tool:** lihat [Mengirim gambar](/id/docs/images) dan [Menggunakan tool](/id/docs/tools).

## Ditolak

Hal berikut mendapat `400 invalid_request`:

- `n` selain 1.
- Output audio (`audio`, `modalities`).
- `web_search_options`.
- Field lama `functions` dan role `function`. Gunakan `tools` dan role `tool` sebagai gantinya.
- Tool selain `function`.
- Content part selain teks dan gambar.
