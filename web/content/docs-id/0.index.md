# Pengantar

_Gateway_ menyediakan Model _chat_ lewat tiga format inferensi standar, Model gambar, _speech_, transkripsi, dan video lewat _endpoint_ masing-masing, serta satu _endpoint_ daftar Model. Untuk menghubungkan _client_ yang sudah memakai salah satu format tersebut:

1. Ganti _base URL_ _client_ dengan _base URL_ _gateway_.
2. Kirim API Key Anda di setiap _request_.
3. Pakai salah satu nama Model yang tersedia di _gateway_.

| Endpoint | Format | Halaman |
| --- | --- | --- |
| `POST /v1/chat/completions` | Chat Completions | [Chat Completions](/id/docs/chat-completions) |
| `POST /v1/messages` | Messages | [Messages](/id/docs/messages) |
| `POST /v1/responses` | Responses | [Responses](/id/docs/responses) |
| `POST /v1/images/generations`, `POST /v1/images/edits` | Gambar | [Gambar, audio, dan video](/id/docs/media#membuat-gambar) |
| `POST /v1/audio/speech` | Speech | [Gambar, audio, dan video](/id/docs/media#speech) |
| `POST /v1/audio/transcriptions` | Transkripsi | [Gambar, audio, dan video](/id/docs/media#transkripsi) |
| `POST /v1/videos`, `GET /v1/videos/{id}`, `GET /v1/videos/{id}/content` | Video | [Gambar, audio, dan video](/id/docs/media#video) |
| `GET /v1/models` | Daftar Model | [Daftar Model](/id/docs/models) |

Setiap _endpoint_ _chat_ membalas dengan satu _response_ JSON. Jika _request_ berisi `"stream": true`, _endpoint_ membalas dengan _stream_ _server-sent events_. _Endpoint_ media tidak mendukung _streaming_.

## Placeholder di contoh

_Test_ _gateway_ menjalankan setiap contoh di halaman ini apa adanya. Ganti _placeholder_ berikut dengan nilai Anda sendiri:

| Placeholder | Ganti dengan |
| --- | --- |
| `https://gateway.example.com` | _Base URL_ _gateway_ ini. Jika operator memberi Anda URL lain, pakai URL tersebut. |
| `$ROUTERLM_API_KEY` | _Environment variable_ yang berisi API Key Anda |
| `my-model` | Nama Model dari [`GET /v1/models`](/id/docs/models) |

## Yang didukung gateway

Semua _endpoint_ _chat_ mendukung teks, _input_ gambar, _streaming_, _function tool_, _reasoning_, dan _structured output_ dengan JSON schema. Lihat [Gambar](/id/docs/images) dan [Tool](/id/docs/tools).

_Service tier_ (`service_tier`) hanya berlaku di Chat Completions dan Responses.

## Batasan

- **_Request body_:** maksimal 20 MB, termasuk gambar _inline_. _File_ yang diunggah lewat _multipart form_ maksimal 25 MB. _Request body_ atau _file_ yang lebih besar ditolak dengan `413 request_too_large`.
- **_Stateless_:** _gateway_ tidak menyimpan percakapan. Kirim seluruh percakapan di setiap _request_, di semua _endpoint_. Di Responses, _gateway_ menolak _stored response_ (`store: true`), `previous_response_id`, dan `conversation`.
- **Tidak didukung:** _request_ yang memakai salah satu fitur berikut ditolak dengan `400 invalid_request`. Pesan _error_-nya menyebutkan fitur tersebut:
  - _Input_ audio, _file_, dan PDF di pesan _chat_. Untuk transkripsi audio, pakai [`POST /v1/audio/transcriptions`](/id/docs/media#transkripsi).
  - _Embedding_.
  - _Hosted tool_, seperti _web search_, _file search_, atau _code execution_. _Gateway_ hanya mendukung _function tool_.
  - _Stored prompt_ dan _background mode_ di Responses.
- **_Field_ yang tidak dikenal:** _gateway_ mengabaikan _field_ yang tidak dipakainya. _Request_ tersebut tidak ditolak.

## Retry

_Gateway_ bisa melakukan _retry_ atas nama Anda sebelum membalas. Jika semua _retry_ gagal, Anda mendapat salah satu _error_ di halaman [Error](/id/docs/errors).
