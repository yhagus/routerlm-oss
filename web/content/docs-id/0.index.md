# Ikhtisar

Gateway menyediakan Model-nya melalui tiga format inferensi standar dan daftar Model. Untuk menghubungkan klien yang sudah memakai salah satu format ini:

1. Atur base URL klien ke base URL gateway.
2. Lakukan autentikasi dengan API Key.
3. Gunakan salah satu nama Model di gateway.

| Endpoint | Format | Halaman |
| --- | --- | --- |
| `POST /v1/chat/completions` | Chat Completions | [Chat Completions](/id/docs/chat-completions) |
| `POST /v1/messages` | Messages | [Messages](/id/docs/messages) |
| `POST /v1/responses` | Responses | [Responses](/id/docs/responses) |
| `GET /v1/models` | Daftar Model | [Models](/id/docs/models) |

Setiap endpoint inferensi menjawab dengan satu respons JSON. Jika permintaan mengatur `"stream": true`, endpoint menjawab dengan stream server-sent events.

## Placeholder dalam contoh

Pengujian gateway menjalankan setiap contoh di halaman ini persis seperti yang tertulis. Ganti placeholder dengan nilai Anda sendiri:

| Placeholder | Ganti dengan |
| --- | --- |
| `https://gateway.example.com` | Base URL gateway ini. Jika operator memberi Anda URL lain, gunakan URL dari operator. |
| `$ROUTERLM_API_KEY` | Variabel lingkungan yang berisi API Key Anda |
| `my-model` | Nama Model dari [`GET /v1/models`](/id/docs/models) |

## Fitur yang didukung gateway

Di setiap endpoint: teks, input gambar, streaming, function tool, reasoning, dan output terstruktur dengan JSON schema. Lihat [Mengirim gambar](/id/docs/images) dan [Menggunakan tool](/id/docs/tools).

## Batasan

- **Body permintaan:** maksimal 20 MB, termasuk gambar inline. Body yang lebih besar mendapat `413 request_too_large`.
- **Stateless:** gateway tidak menyimpan percakapan. Kirim seluruh percakapan di setiap permintaan, di setiap endpoint. Di Responses, gateway menolak respons tersimpan (`store: true`), `previous_response_id`, dan `conversation`.
- **Tidak didukung:** permintaan yang memakai salah satu fitur berikut mendapat `400 invalid_request`. Pesannya menyebutkan fitur tersebut:
  - Input audio, file, dan PDF.
  - Embedding.
  - Pembuatan gambar.
  - Hosted tool, seperti pencarian web, pencarian file, atau eksekusi kode. Gateway hanya mendukung function tool.
  - Prompt tersimpan dan mode background di Responses.
- **Field yang tidak dikenal:** gateway mengabaikan field yang tidak dipakainya. Gateway tidak menolak field tersebut.

## Percobaan ulang

Gateway dapat mencoba ulang permintaan atas nama Anda sebelum menjawab. Jika gateway berhenti mencoba, Anda mendapat salah satu error yang tercantum di halaman [Error](/id/docs/errors).
