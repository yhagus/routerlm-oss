# Error

Permintaan yang gagal mendapat status error HTTP dan body JSON dalam error envelope milik endpoint tersebut. Penanganan error di klien atau SDK Anda tetap berfungsi. Setiap error membawa salah satu kode di bawah.

| Status | Kode | Arti | Tindakan |
| --- | --- | --- | --- |
| 400 | `invalid_request` | Body tidak valid, atau memakai fitur yang tidak didukung gateway. Pesan error menyebutkan masalahnya. | Perbaiki permintaan. Permintaan yang dikirim ulang tanpa perubahan akan gagal lagi. |
| 400 | `no_capable_route` | Model tidak dapat melayani kebutuhan permintaan, seperti gambar, tool, reasoning, JSON schema, atau percakapan sepanjang ini. | Periksa `capabilities` milik Model di [`GET /v1/models`](/id/docs/models). Lalu gunakan Model lain atau hapus fitur tersebut. |
| 401 | `invalid_api_key` | API Key tidak ada, salah, dicabut, atau kedaluwarsa. | Kirim key yang valid (lihat [Autentikasi](/id/docs/authentication)), atau minta key baru kepada operator gateway. |
| 403 | `model_not_allowed` | API Key Anda tidak diizinkan memakai Model ini. | Gunakan Model yang tercantum di `GET /v1/models`, atau minta operator mengizinkan Model ini. |
| 404 | `model_not_found` | Tidak ada Model aktif dengan nama ini. | Cocokkan nama tersebut dengan `GET /v1/models`. |
| 413 | `request_too_large` | Body permintaan lebih dari 20 MB. | Kirim body yang lebih kecil: perkecil ukuran atau resolusi gambar inline, atau kirim gambar melalui URL. |
| 429 | `upstream_rate_limited` | Gateway mencoba ulang atas nama Anda, dan setiap percobaan terkena rate limit. | Tunggu, lalu coba ulang dengan exponential backoff. |
| 502 | `upstream_error` | Gateway mencoba ulang atas nama Anda, dan setiap percobaan gagal. | Coba ulang nanti dengan backoff. |
| 504 | `upstream_timeout` | Gateway mencoba ulang atas nama Anda, dan setiap percobaan melewati batas waktu. | Coba ulang nanti. `max_tokens` yang lebih kecil atau percakapan yang lebih pendek dapat membantu. |

## Envelope

Chat Completions dan Responses memakai envelope ini, dengan kode di `error.code`:

```json
{
  "error": {
    "message": "The Model \"unknown-model\" does not exist",
    "type": "invalid_request_error",
    "param": null,
    "code": "model_not_found"
  }
}
```

Messages memakai envelope ini. `error.type` adalah jenis error Messages, dan `error.code` adalah kode dari gateway:

```json
{
  "type": "error",
  "error": {
    "type": "not_found_error",
    "message": "The Model \"unknown-model\" does not exist",
    "code": "model_not_found"
  }
}
```

Pesan error ditujukan untuk dibaca manusia, dan pesan tersebut dapat berubah. Cocokkan berdasarkan kode.

## Error selama stream

Setelah stream dimulai, status HTTP sudah `200`. Jika permintaan gagal setelah itu, stream berakhir dengan event error dalam format endpoint tersebut, bukan dengan akhir normalnya:

- Chat Completions: error envelope sebagai baris `data:` terakhir, tanpa `data: [DONE]`.
- Messages dan Responses: `event: error`.

Anggap output yang Anda terima sebelum error sebagai output yang belum lengkap.
