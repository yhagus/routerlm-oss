# Overview

The gateway serves its Models through three standard inference formats and a Model list. To connect a client that already uses one of these formats:

1. Set the client's base URL to the gateway's base URL.
2. Authenticate with an API Key.
3. Use one of the gateway's Model names.

| Endpoint | Format | Page |
| --- | --- | --- |
| `POST /v1/chat/completions` | Chat Completions | [Chat Completions](/docs/chat-completions) |
| `POST /v1/messages` | Messages | [Messages](/docs/messages) |
| `POST /v1/responses` | Responses | [Responses](/docs/responses) |
| `GET /v1/models` | Model list | [Models](/docs/models) |

Each inference endpoint answers with one JSON response, or with a stream of server-sent events when the request sets `"stream": true`.

## Placeholders in the examples

The gateway's tests run every example on these pages as written. Replace the placeholders with your own values:

| Placeholder | Replace with |
| --- | --- |
| `https://gateway.example.com` | This gateway's base URL. If your operators gave you a different URL, use their URL. |
| `$ROUTERLM_API_KEY` | An environment variable holding your API Key |
| `my-model` | A Model name from [`GET /v1/models`](/docs/models) |

## What the gateway supports

On every endpoint: text, image input, streaming, function tools, reasoning, and structured output with a JSON schema. See [Sending images](/docs/images) and [Using tools](/docs/tools).

Service tiers (`service_tier`) work on Chat Completions and Responses only.

## Limits

- **Request body:** at most 20 MB, inline images included. A larger body gets `413 request_too_large`.
- **Stateless:** the gateway stores no conversations. Send the whole conversation with every request, on every endpoint. On Responses, the gateway refuses stored responses (`store: true`), `previous_response_id` and `conversation`.
- **Not supported:** a request that uses one of these features gets `400 invalid_request`, with a message that names the feature:
  - Audio, file and PDF input.
  - Embeddings.
  - Image generation.
  - Hosted tools, such as web search, file search or code execution. The gateway supports function tools only.
  - Stored prompts and background mode on Responses.
- **Unknown fields:** the gateway ignores fields it has no use for. It does not refuse them.

## Retries

The gateway may retry on your behalf before it answers. If every retry fails, you get one of the errors listed on [Errors](/docs/errors).
