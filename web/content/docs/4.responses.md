# Responses

`POST /v1/responses` takes a request in the Responses format and answers in the same format. Clients and SDKs built for that format work once you change their base URL to `https://gateway.example.com/v1`.

## Stateless

The gateway stores nothing between requests. Send the whole conversation in `input` every time: earlier output items (messages, reasoning, function calls) can be sent back as input items unchanged. Omitted `store` means `false`.

These are refused with `400 invalid_request`, because they need stored state: `store: true`, `previous_response_id`, `conversation`, `background: true` and stored prompts (`prompt`).

## Request

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "instructions": "You are a concise assistant.",
    "input": "Say hello in one sentence.",
    "max_output_tokens": 256
  }'
```

The response is a `response` object with `status: "completed"` (or `"incomplete"` with `incomplete_details.reason`), its `output` items, and `usage`.

A conversation with earlier turns:

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": [
      { "role": "user", "content": "My name is Ada." },
      { "role": "assistant", "content": "Nice to meet you, Ada." },
      { "role": "user", "content": "What is my name?" }
    ]
  }'
```

With the `openai` SDK:

```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const response = await client.responses.create({
  model: "my-model",
  input: "Say hello in one sentence.",
});

console.log(response.output_text);
```

## Streaming

Set `"stream": true` to receive named server-sent events: `response.created`, `response.in_progress`, the output item events (`response.output_item.added`, `response.output_text.delta`, `response.function_call_arguments.delta`, ...), then `response.completed` or `response.incomplete` with the full response and its usage.

```bash
curl -N https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": "Say hello in one sentence.",
    "stream": true
  }'
```

With the `openai` SDK:

```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

const stream = await client.responses.create({
  model: "my-model",
  input: "Say hello in one sentence.",
  stream: true,
});

for await (const event of stream) {
  if (event.type === "response.output_text.delta") {
    process.stdout.write(event.delta);
  }
}
```

If the request fails after the stream has started, the last event is `event: error` with `{ "type": "error", "code": "...", "message": "..." }` and no `response.completed` follows.

## Other parameters

- **Reasoning:** `reasoning.effort` (`none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`). Reasoning comes back as `reasoning` output items; send them back unchanged in later turns.
- **Structured output:** `text.format` with `{ "type": "json_schema", "name": "...", "schema": { ... } }` or `{ "type": "json_object" }`.
- **Sampling:** `temperature`, `top_p`, `max_output_tokens`.
- **Images and tools:** see [Sending images](/docs/images) and [Using tools](/docs/tools).

## Refused

Besides the stateful features above, these get `400 invalid_request`: tools other than `function` (such as web search, file search, code interpreter or MCP), input items other than messages, reasoning, function calls and function call outputs, content parts other than text and images (such as `input_file` or `input_audio`), and images given by `file_id` (send an `image_url`).
