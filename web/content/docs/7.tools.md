# Using tools

Every endpoint supports function tools: you declare a function with a JSON schema for its arguments, the Model may answer with a call to it, and you run the function and send its result back in the next request. The Model needs the `tools` capability (see [Models](/docs/models)).

Only function tools are supported. Hosted tools such as web search, file search or code execution are refused with `400 invalid_request`.

Because the gateway is stateless, the request that carries a tool result must also carry the conversation before it, including the Model's tool call. Keep tool call ids exactly as you received them.

## Chat Completions

Declare tools in `tools`. A tool call comes back in `message.tool_calls` with `finish_reason: "tool_calls"`. Send the result as a `tool` message with the call's `tool_call_id`:

```bash
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      { "role": "user", "content": "What is the weather in Paris?" },
      {
        "role": "assistant",
        "content": null,
        "tool_calls": [
          {
            "id": "call_123",
            "type": "function",
            "function": { "name": "get_weather", "arguments": "{\"city\":\"Paris\"}" }
          }
        ]
      },
      { "role": "tool", "tool_call_id": "call_123", "content": "18°C, cloudy" }
    ],
    "tools": [
      {
        "type": "function",
        "function": {
          "name": "get_weather",
          "description": "Current weather for a city",
          "parameters": {
            "type": "object",
            "properties": { "city": { "type": "string" } },
            "required": ["city"]
          }
        }
      }
    ],
    "tool_choice": "auto"
  }'
```

`tool_choice` takes `auto`, `none`, `required` or `{ "type": "function", "function": { "name": "get_weather" } }`. `parallel_tool_calls: false` asks for at most one call per turn.

## Messages

Declare tools with an `input_schema`. A tool call comes back as a `tool_use` block with `stop_reason: "tool_use"`. Send the result as a `tool_result` block in the next user message:

```bash
curl https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "messages": [
      { "role": "user", "content": "What is the weather in Paris?" },
      {
        "role": "assistant",
        "content": [
          { "type": "tool_use", "id": "toolu_123", "name": "get_weather", "input": { "city": "Paris" } }
        ]
      },
      {
        "role": "user",
        "content": [{ "type": "tool_result", "tool_use_id": "toolu_123", "content": "18°C, cloudy" }]
      }
    ],
    "tools": [
      {
        "name": "get_weather",
        "description": "Current weather for a city",
        "input_schema": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    ]
  }'
```

## Responses

Declare tools with `"type": "function"`. A tool call comes back as a `function_call` output item with a `call_id`. Send the call back as input, followed by a `function_call_output` item with the same `call_id`:

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": [
      { "role": "user", "content": "What is the weather in Paris?" },
      {
        "type": "function_call",
        "call_id": "call_123",
        "name": "get_weather",
        "arguments": "{\"city\":\"Paris\"}"
      },
      { "type": "function_call_output", "call_id": "call_123", "output": "18°C, cloudy" }
    ],
    "tools": [
      {
        "type": "function",
        "name": "get_weather",
        "description": "Current weather for a city",
        "parameters": {
          "type": "object",
          "properties": { "city": { "type": "string" } },
          "required": ["city"]
        }
      }
    ]
  }'
```

## Streaming tool calls

With `"stream": true`, tool call arguments arrive in pieces: `delta.tool_calls[].function.arguments` on Chat Completions, `input_json_delta` on Messages, and `response.function_call_arguments.delta` on Responses. Join the pieces before parsing the arguments as JSON.
