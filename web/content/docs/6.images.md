# Sending images

Every endpoint accepts images in user messages, either by URL or inline as base64 data. The Model needs the `vision` capability (see [Models](/docs/models)). If it does not have it, the request gets `400 no_capable_route`.

Inline images count toward the 20 MB request body limit. The gateway never stores them.

Each example below sends one image by URL and one inline. Replace `https://example.com/photo.png` with your image's URL, and the inline 1×1 PNG with your image's base64 data and media type.

## Chat Completions

Use an `image_url` content part. Its `url` is a web URL or a `data:` URL.

```bash
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      {
        "role": "user",
        "content": [
          { "type": "text", "text": "What is in this image?" },
          { "type": "image_url", "image_url": { "url": "https://example.com/photo.png" } },
          { "type": "image_url", "image_url": { "url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg==" } }
        ]
      }
    ]
  }'
```

## Messages

Use an `image` content block with a `url` or `base64` source.

```bash
curl https://gateway.example.com/v1/messages \
  -H "x-api-key: $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "max_tokens": 256,
    "messages": [
      {
        "role": "user",
        "content": [
          { "type": "text", "text": "What is in this image?" },
          { "type": "image", "source": { "type": "url", "url": "https://example.com/photo.png" } },
          {
            "type": "image",
            "source": {
              "type": "base64",
              "media_type": "image/png",
              "data": "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="
            }
          }
        ]
      }
    ]
  }'
```

## Responses

Use an `input_image` content part. Its `image_url` is a web URL or a `data:` URL. The gateway stores no files, so it refuses images by `file_id`.

```bash
curl https://gateway.example.com/v1/responses \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "input": [
      {
        "role": "user",
        "content": [
          { "type": "input_text", "text": "What is in this image?" },
          { "type": "input_image", "image_url": "https://example.com/photo.png" },
          { "type": "input_image", "image_url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg==" }
        ]
      }
    ]
  }'
```
