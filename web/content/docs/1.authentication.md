# Authentication

Every request needs an API Key. Ask the gateway's operators for one. It is shown once, when it is created, so keep it somewhere safe. An API Key can be limited to some Models and can expire.

Send the key in either of two headers. Both work on every endpoint.

## Bearer token

The `Authorization` header, which the `openai` SDK sends:

```bash
curl https://gateway.example.com/v1/models \
  -H "Authorization: Bearer $ROUTERLM_API_KEY"
```

## `x-api-key`

The header the `@anthropic-ai/sdk` SDK sends:

```bash
curl https://gateway.example.com/v1/models \
  -H "x-api-key: $ROUTERLM_API_KEY"
```

When a request has both headers, `Authorization` is used.

## When the key is refused

A missing, wrong, revoked or expired key gets `401 invalid_api_key`. A key that may not use the requested Model gets `403 model_not_allowed`. See [Errors](/docs/errors).
