# Models

`GET /v1/models` lists the Models your API Key may use, sorted by name. Use an `id` from this list as the `model` of an inference request.

::code-tabs
```bash
curl https://gateway.example.com/v1/models \
  -H "Authorization: Bearer $ROUTERLM_API_KEY"
```
```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.example.com/v1",
  apiKey: process.env.ROUTERLM_API_KEY,
});

for await (const model of client.models.list()) {
  console.log(model.id);
}
```
::

The response has the model-list shape that Chat Completions clients expect, plus the Model's `kind` and `capabilities`:

```json
{
  "object": "list",
  "data": [
    {
      "id": "my-model",
      "object": "model",
      "created": 1794700000,
      "owned_by": "routerlm",
      "kind": "chat",
      "capabilities": ["vision", "tools", "reasoning", "structured-output"]
    }
  ]
}
```

`kind` says which endpoints serve the Model:

| Kind | Endpoints |
| --- | --- |
| `chat` | [Chat Completions](/docs/chat-completions), [Messages](/docs/messages) and [Responses](/docs/responses) |
| `image` | [`POST /v1/images/generations` and `POST /v1/images/edits`](/docs/media#generating-images) |
| `speech` | [`POST /v1/audio/speech`](/docs/media#speech) |
| `transcription` | [`POST /v1/audio/transcriptions`](/docs/media#transcription) |
| `video` | [`POST /v1/videos`](/docs/media#videos) |

A Model sent to an endpoint of another Kind gets `400 invalid_request`.

`capabilities` says what a request to the Model may use:

| Capability | Requests that need it |
| --- | --- |
| `vision` | [Image input](/docs/images) |
| `tools` | [Function tools](/docs/tools) |
| `reasoning` | Reasoning effort or thinking settings |
| `structured-output` | A JSON schema response format |
| `text-to-video` | A [video](/docs/media#videos) from a prompt alone |
| `first-frame` | A video that starts from a given image |
| `last-frame` | A video that ends on a given image |
| `reference-images` | A video guided by reference images |

A request that needs a capability the Model doesn't have gets `400 no_capable_route`.
