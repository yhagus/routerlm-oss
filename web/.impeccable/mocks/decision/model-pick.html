Chat Completions

PART NO.POST /v1/chat/completions
FORMATchat.completion
STREAMSSE

1 · DESCRIPTION

POST /v1/chat/completions takes a request in the Chat Completions format and answers in the same format.

Clients and SDKs built for that format work once you change their base URL to https://gateway.example.com/v1.

The response is a chat.completion object. Its model is the Model name you sent.

curlTypeScriptCOPY
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      { "role": "user", "content": "Say hello in one sentence." }
    ],
    "max_tokens": 256
  }'
