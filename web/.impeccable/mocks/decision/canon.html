Chat Completions

POST /v1/chat/completions takes a request in the Chat Completions format and answers in the same format. Clients and SDKs built for that format work once you change their base URL.

Request

curlTypeScript
curl https://gateway.example.com/v1/chat/completions \
  -H "Authorization: Bearer $ROUTERLM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "my-model",
    "messages": [
      { "role": "user", "content": "Say hello in one sentence." }
    ]
  }'
